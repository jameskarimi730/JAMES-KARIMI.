# James Karimi — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — add your own profile photo here

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `james-karimi-portfolio`.
2. Upload all files and folders in this project. Keep `index.html` in the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The page will show your website URL.

## Add your profile photo
Place your photo in the `assets` folder and name it exactly `profile.jpg`.
Recommended: a clear portrait image in JPG format.

## Before publishing
Check that the email, phone number and social media links are correct. You can edit them in `index.html`.
